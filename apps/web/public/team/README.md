# Team photos

Drop headshots here to replace the branded initials avatars on the landing
`#team` section. No code changes needed — the filename is the member's slug:

| File | Member |
|------|--------|
| `sergiu-ciausu.jpg` | Sergiu Ciausu |
| `andrei-tutea.jpg`  | Andrei Iulian Tutea |
| `david-marin.jpg`   | David Marin |
| `rares-ilasoaia.jpg`| Rares Ilasoaia |

Square images, ~320×320 px or larger, JPG. Until a file exists (or if it fails
to load) the card shows a gradient disc with the member's initials.
